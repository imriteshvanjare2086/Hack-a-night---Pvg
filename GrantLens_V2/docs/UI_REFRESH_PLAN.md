# SATARKK UI Refresh & Bug-Fix Plan

This plan documents the targeted UI refresh and bug fixes across all 14 items per the specification.

---

## The 14 Items: Implementation & Root Cause Matrix

| Item # | Title | Target Files | Suspected Root Cause & Fix Strategy |
|:---:|---|---|---|
| **1** | **Rename website to "SATARKK"** | `index.html`, `src/components/layout/Layout.tsx`, `src/pages/Login/index.tsx`, `src/pages/Settings/index.tsx`, `src/pages/Reports/index.tsx`, `src/components/common/Common.tsx` | User-visible branding strings in titles, headers, logos, and reports currently display "GrantLens". Replace user-visible text with "SATARKK" without modifying code identifiers, routes, storage keys, or package names. |
| **2** | **Move logout into profile dropdown** | `src/components/layout/Layout.tsx`, `src/styles/global.css` | Standalone `<button>Logout</button>` is currently placed in `utility-bar` header; clicking `.profile` opens an alert dialog rather than an accessible dropdown menu. Move Logout into an accessible profile dropdown with Escape/click-outside handling and proper ARIA roles. |
| **3** | **Visible font size & weight everywhere** | `src/styles/global.css`, `src/components/common/Common.tsx` | Base font size is currently 13px with sub-elements at 10-11px and low-contrast muted grays (`#8b9caf`). Raise base body text to >= 14px, captions to >= 12-13px, eliminate weights below 400, and ensure WCAG AA (4.5:1) contrast. |
| **4** | **Government-style font family** | `package.json`, `src/main.tsx`, `src/styles/global.css` | Font family is currently generic Inter/Segoe UI. Install `@fontsource/noto-sans` (self-hosted offline) and configure `"Noto Sans", "Open Sans", Arial, Helvetica, sans-serif` globally and on all form controls (`font-family: inherit`). |
| **5** | **Dropdown CSS & text overlap site-wide** | `src/styles/global.css`, `src/components/common/Common.tsx` | Native and custom selects have inconsistent heights, lacking ellipsis truncation, and dropdown menus risk clipping by `overflow: hidden` or lower z-index than the Cytoscape canvas. Standardize select styles, add ellipsis with title tooltips, and ensure `z-index: 50`. |
| **6** | **Card hover effects & transitions** | `src/styles/global.css` | Panels and KPI cards lack interactive feedback. Add subtle institutional lift (`transition: transform 150ms ease-out, box-shadow 150ms ease-out`, `hover:-translate-y-0.5 hover:shadow-md`) while respecting `prefers-reduced-motion`. |
| **7** | **No secrets exposed on frontend** | `src/pages/Login/index.tsx`, `src/pages/Settings/index.tsx` | Login component currently has `<p>Demo: auditor@grantlens.demo / GrantLens123</p>` rendered directly in the DOM. Remove credential hint text. Verify `.env` and client bundles contain no real API keys, tokens, or private paths. |
| **8** | **Anomaly category chart** | `src/pages/Overview/index.tsx` | Anomaly categories in Overview are not sorted descending, YAxis labels are truncated (155px width), bars are blue (`#4c7fae`) instead of red (`#C62828`), and values lack end-of-bar labels. Sort data descending, expand YAxis, apply red bar color, and add tooltips/labels. |
| **9** | **Risk Clusters: review status filter & alignment** | `src/components/tables/ServerClusterTable.tsx`, `src/components/tables/ClusterTable.tsx`, `src/styles/global.css` | Status filter values mismatch backend schema/regex requirements (`"Needs Review"` vs `"NEEDS_REVIEW"`), causing 422 errors or failing to match SQL records. Align filter options with exact backend enum values, fix reset state, and adjust button alignment in table rows. |
| **10** | **Beneficiaries: dropdowns & search boxes** | `src/pages/PriorityQueue/index.tsx`, `src/components/common/Common.tsx` | Search inputs trigger un-debounced queries on every keystroke, filter changes don't consistently reset page to 1, and reset action does not clear all fields. Implement 300ms debounce on search, wire reset to restore page 1 and clean filters. |
| **11** | **Network Explorer dropdowns** | `src/pages/NetworkExplorer/index.tsx`, `src/components/graphs/GraphView.tsx`, `src/styles/global.css` | Cluster selector and node controls risk z-index obscuration behind Cytoscape canvas; ensure dropdown menus have higher stacking context (`z-index: 50`) and trigger smooth graph updates. |
| **12** | **Remove repeated features** | `src/components/layout/Layout.tsx`, `src/app/router/AppRoutes.tsx` | Priority Review Queue is currently rendered twice in navigation (under both `/beneficiaries` and `/review-queue` with identical icons and components). Consolidate into canonical routes and clean up redundant sidebar entries. |
| **13** | **Sidebar scroll position resets on click** | `src/components/layout/Layout.tsx`, `src/styles/global.css` | `useEffect([location.pathname])` executes `window.scrollTo(0, 0)`, which resets window and sidebar scroll. Confine scroll-to-top strictly to main workspace container and preserve sidebar scroll position across navigation. |
| **14** | **Settings: remove all secrets** | `src/pages/Settings/index.tsx` | Ensure Settings screen displays strictly non-sensitive diagnostics (health, active audit, formats, version) with no internal file paths, environment dumps, or database URLs. |
